Auto-refresh: a GitHub Action fetches fresh data from Stooq server-side every morning and updates data.json — this page just displays whatever data.json currently holds, so it's up to date whether or not this tab is ever open.
Why this way: Stooq's servers don't send the CORS headers browsers require, so this page cannot fetch price data directly from JavaScript. Fetching server-side (outside a browser) sidesteps that restriction entirely.
Prices: daily close data from Stooq, typically reflecting the prior close outside of market hours.
